# Keeping Up with the Capital

Weekly notes on venture capital and startups for enthusiasts, with a focus on India. Published every Friday at 6 PM IST.

Live site: https://pgwrites.github.io/keeping-up-with-the-capital/

## How this repo works

- `_posts/`: one Markdown file per edition. Edit an edition by editing its file.
- `STYLE.md`: the editorial rules every edition follows. Change the rules here.
- `_data/memory.yml`: every investor, company and theme, with the editions they appeared in.
- `_memory/`: memory pages, created once something appears in two editions.
- `methodology.md`: the public "how the digest is curated" page.
- `_layouts/`, `_includes/`, `assets/`: the design. Change it once and every edition updates.

The site is built by GitHub Pages (Jekyll) from the `main` branch.
